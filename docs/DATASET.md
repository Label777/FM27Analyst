# Датасет скриншотов FM27 (этап 3)

Распознавание экрана обучается на реальных скриншотах **русской версии FM27**. Без них этап 3 не начать: шаблоны, OCR-регионы и классификатор экранов строятся по вашим снимкам.

## Самый простой способ: автосъёмка

1. Один раз: `pip install -e core[windows]`
2. FM27 в режиме **«Окно без рамки»**, в отдельной консоли:
   ```
   python tools/collect_screens.py --out dataset --auto 4
   ```
3. Просто сыграйте 2–3 матча как обычно: заходите в тактику, состав, статистику, профили запасных, превью соперника. Утилита сама снимает окно игры раз в 4 секунды, только когда экран изменился.
4. `Ctrl+C`, заархивируйте папку `dataset` и пришлите. Разметку по типам экранов я сделаю сам.

Для старта хватит 150–300 снимков. Таблица ниже — ориентир, какие экраны важно открыть хотя бы несколько раз.

## Ручной режим с метками

1. Установите зависимости на Windows (один раз):
   ```
   pip install -e core[windows]
   ```
2. Запустите FM27 в режиме **«Окно без рамки»** (Настройки → Экран).
3. В отдельной консоли:
   ```
   python tools/collect_screens.py --out dataset
   ```
4. Играйте как обычно и нажимайте `Ctrl+Alt+цифра`, когда на экране нужный вид. Утилита снимает только окно игры.

| Клавиши | Экран | Что должно быть видно | Минимум |
|---|---|---|---|
| Ctrl+Alt+1 | Матч | Плашка счёта и минуты, поле, squad bar | 60 |
| Ctrl+Alt+2 | Статистика матча | Владение, удары, в створ, xG, передачи | 60 |
| Ctrl+Alt+3 | Тактика | Схема в владении и без мяча, роли | 40 |
| Ctrl+Alt+4 | Состав | Оценки, иконки усталости, карточки | 50 |
| Ctrl+Alt+5 | Профиль игрока | Атрибуты (особенно запасных) | 30 |
| Ctrl+Alt+6 | Анализ | Heat Maps, Action Zones, Pass Maps | 30 |
| Ctrl+Alt+7 | Превью соперника | Вероятный состав и схема | 20 |
| Ctrl+Alt+8 | Лента dugout | Сообщения штаба о перестроениях соперника | 40 |
| Ctrl+Alt+0 | Другое | Любые экраны, которые не подходят выше (для класса «прочее») | 30 |

## Что важно

- **Разные моменты матча**: начало, после гола, после замены, концовка, разный счёт — цифры на плашке должны меняться.
- **Разные разрешения**, если есть возможность: 1920×1080, 2560×1440, 3840×2160. И масштаб интерфейса 100% и 125–150%.
- **Стандартный скин**. Кастомные скины — позже, отдельной партией.
- Проверить прогресс: `python tools/collect_screens.py --out dataset --report`.

## Что делать с датасетом

Заархивируйте папку `dataset` и пришлите. По ней будут сделаны:

1. Каталог экранов русской локализации и точные названия полей (правки, роли, позиции) — справочник `fm27_reference.json` будет сверен (`verified_ru: true`).
2. Классификатор типа экрана (ONNX, работает офлайн).
3. Экстракторы для счёта, минуты, статистики, оценок, усталости и ленты dugout.
4. Регрессионный набор: после каждого патча FM27 прогоняем распознавание по датасету и видим, что сломалось.
