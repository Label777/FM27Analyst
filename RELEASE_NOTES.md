Обычная программа для Windows: установщик, ярлык, без Python и чёрных окон.

- Помощник сам ставит и обновляет плагин FM27 Analyst Bridge в игре (нужен BepInEx — например, из FM27 Exporter).
- Связь с игрой: таблицы состава, поиска и шорт-листа целиком, с игровой датой; тексты экрана для матча.
- Распознаются русские колонки вида «Обзор» состава FM27.
- Обновления: при новой версии вверху появится кнопка «Обновить».
