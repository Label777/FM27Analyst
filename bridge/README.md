# FM27 Analyst Bridge

Плагин BepInEx 6 (IL2CPP) для Football Manager 27. Читает интерфейс игры и передаёт его ядру FM27 Analyst
(`http://127.0.0.1:8727`). Работает только на этом компьютере.

**Только чтение.** Мост не нажимает кнопки, не меняет тактику, состав, трансферы и сейв. Единственное действие
с интерфейсом — прокрутка списка при чтении таблицы целиком (как у FM27 Exporter); прокрутка возвращается на место.
Мост не читает память игры по адресам и не показывает скрытые параметры: только то, что видно на экране.

## Что умеет

| Команда (кнопка в приложении) | Что делает |
|---|---|
| «Забрать таблицу с экрана» | Самая большая таблица на экране целиком (все строки, видимые колонки) + тексты шапки для игровой даты |
| «Какие таблицы на экране» | Список таблиц: экран, колонки, строки |
| «Снять тексты экрана» | Все видимые тексты с позицией и путём в дереве интерфейса |
| «Авто-снимки» | Раз в N секунд тексты экрана, если что-то изменилось (живой матч) |

Игровая дата берётся из текстов экрана (`Чт 26 ноя 2026`, `26.11.2026`, `Thu 26 Nov 2026`). Не нашлась — так и пишем.

## Устройство

- `src/FM27Bridge.Core` — связь с ядром (фоновый поток, очередь), разбор снимков экрана. Без Unity, с тестами.
- `src/FM27Bridge` — плагин: `BridgeBehaviour` (команды в главном потоке Unity), `TableGrab`, `ScreenReader`.
- `vendor/fm27-exporter` — чтение таблиц из FM27 Exporter (MIT, © 2026 v1adicke), коммит в `COMMIT`.
- `tools/stubs` — заглушки API для проверки компиляции без игры.
- `tools/fake-game` — «игра без игры»: проверка связи с ядром.

## Сборка

Нужна установленная игра с BepInEx 6 (её первый запуск создаёт `BepInEx/interop`). SDK .NET 8, пакеты NuGet не нужны.

```
dotnet run --project tests/FM27Bridge.Tests                      # логика моста
dotnet build tools/stubs/CompileCheck.csproj                      # компиляция без игры
dotnet build src/FM27Bridge -c Release -p:Game="<папка FM27>"     # настоящий плагин
```

Результат `src/FM27Bridge/bin/Release/net6.0/FM27AnalystBridge.dll` кладётся в `<папка FM27>/BepInEx/plugins/FM27AnalystBridge/`.
Удаление — удалить эту папку. Настройки — `BepInEx/config/local.fm27analyst.bridge.cfg`.
