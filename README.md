# FM27 Real-Time Analyst

AI-помощник главного тренера для Football Manager 27: следит за матчем по экрану, находит проблемы и даёт конкретные советы в терминах FM27 — с основанием и рисками.

Исследование и архитектура: см. документ «FM27 Real-Time Analyst — техническое исследование».

## Быстрый старт (Windows)

Нужно: Python 3.11+, Node.js 20+, Rust (для оболочки Tauri).

```powershell
pip install -e "core[windows,dev]"
cd app; npm install; cd ..

# необязательно — AI-аналитик вместо советов по правилам
$env:ANTHROPIC_API_KEY = "sk-ant-..."

scripts\start-dev.bat
```

Откроется виджет в левом верхнем углу (перетаскивается за верхнюю строку). Горячих клавиш нет — всё кнопками: **«Анализ экрана»** — снимок текущего экрана FM27, **«Панель»** — открыть/скрыть расширенную панель, **«Голос»** — озвучивать советы. В панели есть те же кнопки и «Свернуть в виджет»; крестик панели тоже просто прячет её, выход — закрыть виджет. Клавиши игры и плагинов экспорта (F8/F9) остаются свободными. В панели: «Сейв и матч» → «Запустить демо-матч».

Без Rust можно запустить в браузере: `python -m fm27_analyst.server` и `cd app && npm run dev`, затем открыть http://localhost:1420 (панель) и http://localhost:1420/?view=compact (виджет).

Установщик: `scripts\build-windows.ps1`.

## Скаутинг: как загрузить данные из FM27

С FM26 SI убрала встроенную выгрузку списков, но для FM27 её вернули плагины BepInEx. Они читают только таблицу на экране и не трогают сейв:

- **FM27 Exporter** (v1adicke) — F8 на любом списке → HTML/RTF/CSV в `Документы\Sports Interactive\Football Manager 27\exports`. **Ctrl+F8** добавляет в вид все 47 атрибутов — без атрибутов Tactical Fit не посчитать.
- **FM-View-Exporter** — F9 → CSV/HTML с Unique ID (помогает отслеживать игрока между выгрузками).

Дальше: панель → «Главный скаут» → «Наш состав…» (экран состава) и «Поиск игроков / рынок…» (экран поиска игроков). Установка плагинов — ваше решение: это мод для игры; сам помощник в игру ничего не внедряет.

Без игры: «Главное меню» → «Загрузить демо-выгрузки» (рынок, две выгрузки состава с разницей 6 месяцев, соперник) и «Добавить демо-сезон» (18 матчей). Все имена вымышленные.

## Как устроено

```
core/fm27_analyst/
  models.py      снимок матча; у каждого значения — источник и уверенность
  timeline.py    история снимков, изменения, проверенные факты, xG за 15 мин
  rules.py       детекторы: стерильное владение, всплеск xG соперника, перестроение,
                 усталость, падение оценки, травма, риск второй жёлтой, «тактика работает»
  gate.py        не чаще 1 совета в 5 игровых минут, критичное — сразу, отклонённое не повторять
  advisor.py     советы по правилам + подбор замены по профилю атрибутов линии
  reasoner.py    LLM: только факты из списка, ответ — JSON, проверка и отбраковка выдумок
  storage.py     одна SQLite-база на сохранение; итог совета через 15 минут
  capture/       захват окна FM27
  vision/        фильтр изменений и каркас распознавания (этап 3)
  club/          отделы клуба: importer (CSV/HTML, диапазоны «9-11»), db (база сейва, ДНК),
                 fit (Tactical Fit 0–100 с разбором), search (запрос на русском → фильтры),
                 report (отчёт из 10 разделов, оценка, BUY/WATCH/AVOID, сравнение, таланты), squad
  club/director.py           спортивный директор и режим трансферного окна
  club/finance.py, youth.py  финансовый директор, развитие молодёжи
  club/opposition.py         разведка соперника (факты отдельно от гипотез)
  season.py                  аналитик сезона; итоги вручную или из отслеженных матчей
  departments.py             9 отделов над общей базой: главное меню, единое заключение, маршрутизация вопросов
  data/role_profiles.json    профили позиций, модификаторы стиля, схемы
  data/export_columns.json   сопоставление заголовков выгрузок (EN; RU — сверить)
  data/fm27_reference.json   разрешённые настройки FM27 (сверить с русской локализацией)
app/             React-интерфейс (русский) + src-tauri (оболочка)
tools/collect_screens.py     сбор датасета скриншотов
```

Данные: `%APPDATA%\FM27Analyst\saves\<клуб>__<сейв>.sqlite`.

Тесты: `cd core && python -m pytest -q`.

## Что ещё нужно с ноутбука с игрой

1. Одна выгрузка любого списка из FM27 через FM27 Exporter (с атрибутами) — сверить русские заголовки колонок.
2. Датасет скриншотов ([docs/DATASET.md](docs/DATASET.md)) — для распознавания экрана (этап 3).
3. Первый запуск оболочки на Windows: виджет поверх игры и его кнопки, сворачивание панели.

## Следующий шаг

Снять датасет русской версии FM27 по [docs/DATASET.md](docs/DATASET.md) и прислать — после этого этап 3: классификатор экранов и извлечение счёта, статистики, оценок, усталости и ленты dugout.

## Связь с игрой (плагин FM27 Analyst Bridge)

Папка `bridge/` — плагин BepInEx для FM27, который читает интерфейс игры (таблицы и тексты экрана) и передаёт
их ядру: актуальные игроки на текущую игровую дату без ручных выгрузок, тексты экрана матча для живого разбора.
Только чтение — в игре ничего не нажимает и не меняет. Подробности: `bridge/README.md`.
В приложении — раздел «Связь с игрой» и кнопка «Таблицу» в виджете.

## Установка на Windows и автообновление

1. Скачайте `release/` из этого репозитория (или архив релиза) и запустите `Запустить FM27 Analyst.bat`.
2. При каждом запуске `tools/update.ps1` сверяет `release/VERSION` с GitHub, при новой версии скачивает
   ядро, интерфейс и плагин, а плагин кладёт в `BepInEx/plugins/FM27AnalystBridge` найденной FM27 (если игра закрыта).
3. Новый релиз: `GAME="<папка FM27 с BepInEx>" scripts/make-release.sh`, затем коммит в `main`.
